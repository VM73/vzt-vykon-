# Vzduchový výkon VZT

Mobilní webová appka pro servisní techniky VZT — výpočet vzduchového výkonu
z rychlosti proudění a rozměrů potrubí, z tlaku a k-faktoru ventilátoru,
cílové rychlosti a účinnosti rekuperace.

Běží na https://vm73.github.io/vzt-vykon-/ — v telefonu: Safari → Sdílet →
Přidat na plochu.
